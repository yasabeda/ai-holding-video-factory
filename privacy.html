Privacy Policy

This policy describes how AI Holding Video Factory ("the application") accesses, uses, stores and shares Google user data. The application is operated by Synoria AI Corporation ("the operator").

1. YouTube API Services

The application uses YouTube API Services. By using the application you also agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

2. Who uses the application

The application is a private tool. It is used only by the operator, with Google accounts and YouTube channels that the operator owns or manages. It is not offered to the public.

3. Data the application accesses

With the consent given on the Google consent screen, the application accesses:

  • Account identity: the email address and Google account identifier of the account that signs in. Used only to confirm that the expected account and channel were connected.
  • Channel and video data: the channel identifier and title, and for videos the application uploaded: identifiers, titles, descriptions, visibility, scheduled publication time, processing status, thumbnails and captions.
  • YouTube Analytics data: report data for the connected channels, such as views, watch time, audience retention, subscribers gained and traffic sources.

The application uploads videos, thumbnails and captions and sets video details on the connected channels. It does not access channels that have not been connected.

4. How the data is used

  • To upload and schedule the operator's videos and confirm that the upload matches what was intended.
  • To avoid uploading the same video twice.
  • To understand how published videos performed and improve later videos.

The data is not used for advertising, is not sold, and is not used to train generalised artificial-intelligence models. Any automated analysis runs on the operator's own computer.

5. Storage and security

  • All data is stored on the operator's own computer. The application has no server and no cloud database.
  • OAuth tokens are stored encrypted with the Windows Data Protection API under the operator's Windows account.
  • Channel identifiers, the account email, upload records and analytics reports are stored in local files and a local database on the same computer.

6. Sharing

Google user data is not shared with, transferred to or disclosed to any third party. Data moves only between the operator's computer and Google's servers.

7. Retention and deletion

  • OAuth tokens are kept while a channel stays connected and are replaced when the channel is re-authorised.
  • Upload records are kept as long as the operator runs the application, so that duplicate uploads can be prevented.
  • Analytics data is kept while the channel's authorisation remains valid and is refreshed from YouTube when new reports are fetched.
  • There is no automatic deletion schedule. Deletion is carried out manually by the operator. When a deletion request is received at the contact address below, the operator deletes the stored token and the stored data for that account within 7 calendar days. When access is revoked through Google, the operator deletes them within 30 calendar days.
  • Deleting data held by the application does not delete videos or data on YouTube itself.

8. Revoking access

You can revoke the application's access to your Google account at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the application can no longer access the account.

9. Cookies and this website

The application does not use cookies and does not place or read information on other people's devices. This website is a static site hosted by GitHub Pages; it sets no cookies of its own and has no analytics or advertising. GitHub may log visitor IP addresses as described in GitHub's own privacy statement.

10. Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

11. Changes

If this policy changes, the new version will be published on this page with a new date.
